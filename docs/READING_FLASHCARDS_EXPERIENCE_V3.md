# 阅读与抽卡体验 V3 · 单轮验收与回归

版本：2026-11-10。升级目标是在不重做视觉资产、不修改正文内容的前提下改善中英学习及操作体验。

## 不变项（严格）
- 源 Markdown 26 章、网站镜像全文一致；210 张词卡的 ID、释义、例句和 7 个分类不改。
- 原有 `five-github-words-v1`、`github-guide-progress-v1` 本地记录保留。
- 现有深绿/青色主题、Lucide 本地图标、PC/H5 网格及页面路径 `#/home`、`#/24`–`#/26`、`#/words` 保留。
- 所有示例只使用已经公开的通用知识内容；不添加任何具体私有项目名称或仓库路径。

## 本轮实现
### 文档阅读
- PC/H5 默认正文 18px，16–22px 调节，原字号存储独立，不污染章节或词卡进度。
- 中英对照术语表按现有表格内容判断，支持表格/逐条卡片两种阅读模式。
- 英文术语可复制；每个表的中文解释、用途、场景内容完全保留。
- 章节顶部轻量阅读工具栏、阅读进度条、快捷进入英语抽卡。
- 正文标题、列表、引用、代码示例与表格的字号/行距统一提升。

### 抽卡学习
- 点击真实翻面：原地切换 `flipped` 类，而非重绘整个视图，保留 3D 动画。
- 解释与场景示例分层，原有「英文：中文」例句分开两行呈现但不增删字符。
- 保留随机抽卡、上一张/下一张、中文反向抽卡、发音、收藏、待复习和已掌握。
- 学习状态仍在原 localStorage 键中，切换方向和分类不清空进度。

## 验收视口
| 视口 | 关注点 |

| 1920×1080 | 阅读宽度、左右目录、表格对照、卡片切换是否自然 |
| 1440×900 | 主栏字号、阅读工具栏是否遮挡正文、抽卡操作是否易达 |
| 1366×768 | 工具栏按钮换行、表格滚动与语言对照可读性 |
| 390×844 | H5 单列布局、工具栏紧凑、表格/卡片切换、手势切卡 |
| 375×812 | 最窄常见手机下字号、操作按钮及中英内容是否溢出 |

## 功能人工验收
1. PC 打开 `#/26`，连续点击 A＋ 到 22px，回到 16px；刷新后字号应保留。切换「术语突出」，刷新后偏好保留。
2. 章节中带英文/中文的术语表可在表格、卡片模式切换，复制术语正确；段落和表格的原文无变化。
3. PC `#/words`：翻面有动画，英文与中文例句按行展示；待复习/已掌握标记生效并切到下一张。
4. H5 `#/words`：点击翻面、左右手势、朗读、搜索、收藏均正常，数据不丢失。
5. H5 `#/24`–`#/26`：正文无需强制缩小页面，底部文字、表格和导航完整，无水平整页滚动。
6. 深浅主题的正文与示例文本均具备阅读对比度。
7. 切换到新版前已有的学习进度、收藏及章节已读状态应继续存在。
