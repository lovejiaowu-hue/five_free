# PC / H5 自适应 V2.0 · 交付与验收说明

版本：V2.0 · 2026-11-10

## 目标
在单站点、同一套 HTML/JS/内容资产上，优化 PC 桌面学习体验，保留 H5 的单列操作习惯。不是拆分两个互相独立的模板。

## 设计原则
1. **桌面优先的信息组织**：电脑端分栏、提高阅读字号与内容利用率，不把 H5 简单放大。
2. **手机体验无损**：移动端菜单、翻卡、切换、朗读、标记及词汇表继续可用。
3. **内容与状态唯一来源**：24 章 Markdown、210 张卡片、ID、localStorage 键和 URL Hash 路由不改变。
4. **图标来源治理**：使用现有本地 Lucide 资产，无外部 CDN 和新增自绘功能图标。
5. **纯静态 GitHub Pages**：无构建依赖，支持下载后离线浏览。

## 文件范围
- `index.html`：引入最终优先级的响应式 V2 CSS 文件。
- `assets/css/responsive-v2.css`：桌面排版、首页 Dashboard、抽卡双栏、平板与移动断点。
- `assets/js/site.js`：增加 PC 首页「继续学习」工作台，未修改手册内容和路由算法。
- `assets/js/flashcards.js`：将分类和学习统计放入侧栏，抽卡功能与本地存储不改。
- `scripts/test-responsive-v2.mjs`：断点、HTML 结构及功能兼容性验证。
- `.github/workflows/validate-manual.yml` / `deploy-pages.yml`：PR / main 上运行新的 V2 校验。

## 布局
| 视口 | 处理方式 | 主功能 |
|---|---|---|
| ≤760px | H5 单列 | 折叠菜单、顺序抽卡、左右滑动 |
| 761–1199px | 平板/小电脑两栏壳体 | 左侧导航、中间内容；不显示第三栏 |
| 1200–1499px | PC 两栏壳体 | 首页 Dashboard；抽卡分类侧栏 + 中央卡片 |
| 1500–1799px | PC 三栏文档 | 全局导航 + 文档/卡片主体 + 本页索引 |
| ≥1800px | 宽屏升级 | 加宽版心及学习卡片 |

## 验收步骤（人工）
- **1366×768 / 1440×900 / 1920×1080**：首页英雄区与快捷学习卡片协调；正文不出现水平页面滚动；正文适于长时间阅读；本章目录可用。
- **PC 抽卡**：分类、进度及主题在左，筛选、翻面、标记、上一张/下一张在右；支持词汇总表/搜索；快捷键正常。
- **375×812 / 390×844**：导航开关、章节阅读、表格横向滚动、抽卡按钮、收藏/复习操作正常；无异常挤压。
- **路由**：`#/home`、`#/24`、`#/words` 刷新直达正常，搜索与章节跳转正常。
- **进度**：旧版已读章节和已掌握/待复习/收藏记录可继续使用；数据只保存在当前浏览器。
- **暗色模式**：正文、状态提示、按钮和卡片内容对比可读。

## 自动化门禁
- `node --check assets/js/site.js`
- `node --check assets/js/flashcards.js`
- `node scripts/check-site.mjs`
- `node scripts/test-flashcards.mjs`
- `node scripts/test-responsive-v2.mjs`

自动化检查通过不等于真实浏览器视觉验收，后者仍需针对指定视口查看实际页面。

## 回滚
当前版本只涉及样式与视图结构。如 PC 视觉不合预期，可通过独立 PR 回退 V2 相关改动，原有 Markdown、词库和用户 localStorage 不必迁移。
